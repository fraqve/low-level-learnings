# low-level-learnings
My Python Learning Lab 🚀
Welcome! This repository is a collection of my projects as I teach myself Python. It ranges from my very first steps in Object-Oriented Programming to more complex multi-threaded network tools.

🛠 Project Categories
🌐 Network & Security (Current Focus)
Multi-Threaded Ping Sweeper: A cross-platform tool to discover live hosts. Features ThreadPoolExecutor for speed and argparse for a professional CLI experience.

File Integrity Monitor: A script to track file changes using hashing to ensure data hasn't been tampered with.

[In Progress] TCP Port Scanner: Learning to use Python sockets to identify open services on a target IP.

💾 Data & Logic
JSON Banking Vault: A system that simulates bank account management. This project taught me how to use JSON for permanent data storage and how to handle user authentication logic.

Text-Based RPG Crawler: A game loop project focusing on state management, random events, and player input handling.

🏗 Evolutionary Steps (The "Archives")
OOP Entity Project: My first real dive into Object-Oriented Programming. It’s a bit messy, but it’s where I learned about classes, inheritance, and why structure matters!

📈 What I've Mastered So Far
Concurrency: Moving from sequential code to parallel execution.

Persistence: Reading and writing to files to save program state.

Platform Independence: Writing code that works on both Windows and Linux.

Clean CLI Design: Making tools that are easy to use via the terminal.
